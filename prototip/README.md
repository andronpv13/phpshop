# 🛒 Прототип интернет-магазина PHPShop 6.6.5

> Создан строго по документации проекта. Все файлы самодостаточны.

## 🚀 Как запустить
1. Откройте `index.html` в любом современном браузере
2. Для просмотра на мобильном: используйте DevTools (F12) → Toggle Device Toolbar

## 🔗 Связь с документацией
| Страница | Фаза из документации | Реализовано |
|----------|----------------------|-------------|
| Каталог / Главная | Фаза 1, 2 | Front Controller эмуляция, категории, товары |
| Карточка товара | Фаза 2, 4 | `product.class.php` логика, `vendor_sku`, корзина |
| Корзина | Фаза 2, 5 | `cart.class.php`, сессионное хранение (localStorage) |
| Оформление заказа | Фаза 3, 5 | Валидация, доставка, оплата, статусы |
| Админка | Фаза 1, 2 | CRUD эмуляция, дашборд, безопасность (mock) |

## ⚙️ Технологии
- Чистый HTML5 / CSS3 / Vanilla JS
- CSS Variables, Grid/Flexbox, Mobile-First
- `localStorage` для состояния корзины
- Zero-build, работает offline
